# 預設模組

**預設模組**會將可重用的子圖封裝為一個節點。CodefyUI 內建 `lstm_sequence`、`simple_cnn_classifier` 與 `training_pipeline` 預設模組。你也可以將畫布匯出為預設模組，並在其他圖中使用。

## 使用預設模組 {/* #using-a-preset */}

預設模組會出現在側邊欄**節點**分頁中、位於節點分類下方的**預設組合**分類，也會出現在雙擊畫布所開啟的快速搜尋。該分頁的搜尋框同時會比對節點名稱與預設模組名稱。預設模組和分頁中的其他項目一樣，直接拖曳到畫布上即可。放置後，預設模組的行為與其他節點相同。它會暴露子圖內所有未連接的連接埠，以及每個內部節點的所有非 secret 參數。從 `Start` 拉到已放置預設模組的 Trigger 連線，會啟動模組內每個沒有內部連線連入的節點；接在預設模組未暴露之連接埠上的連線則會被拒絕。

若要設定已放置的預設模組，請雙擊該節點，或在**節點設定**面板或節點詳情中選擇**設定內容**。設定視窗會列出內部節點，並依節點分組顯示暴露的參數。**套用**會將選擇的值寫入內部節點。

執行前，圖引擎會將每個預設模組**展開**為其內部節點。預設模組會封裝節點，但不會增加獨立的執行階段。

## 可攜式定義 {/* #portable-definitions */}

儲存或匯入的圖可以內嵌其使用的預設模組定義。這些定義屬於該圖，因此重新載入登錄資料，或停用提供該預設模組的外掛，都不會移除已開啟圖中的副本。若已安裝的預設模組同名，該圖內的內嵌定義優先；其他圖所見的已安裝面板不受影響。**Map** 節點是例外：它只會在已安裝的預設模組中尋找 `subgraph` 參數指定的名稱，因此不會使用內嵌定義；沒有同名的已安裝預設模組時會執行失敗。

儲存與匯出只會包含圖仍有參照的定義，包括只存在於收合區塊內的預設模組。secret 參數值仍只存在於目前 session，不會被寫入可攜式定義、儲存圖或匯出圖。

## 建立自己的預設模組 {/* #creating-your-own */}

匯出預設模組時會包含整張畫布。你不能只選取部分節點，也不能逐項選擇要暴露的內容。請使用只包含該預設模組所需節點的畫布；通常新分頁最簡單。

1. 建立子圖。每個未連接的連接埠都會成為預設模組連接埠，因此所需的輸入與輸出都應保持未連接。圖中至少要有一個未連接的連接埠，否則伺服器會拒絕匯出。匯出前請展開所有收合區塊。預設模組不能包含區塊定義，所以伺服器會拒絕含有收合區塊的畫布。
2. 開啟工具列的**匯出**選單，選擇**匯出為子圖**，然後輸入名稱。若其他預設模組已使用該名稱，伺服器會拒絕並回傳 `409`。
3. 伺服器會將每個暴露的連接埠命名為 `<node>_<port>`，並暴露依節點型別分組的所有非 secret 參數。接著，伺服器會寫入預設模組並重新載入面板。此預設模組隨後會出現在**節點**分頁的**預設組合**分類與快速搜尋中。

預設模組以 JSON 儲存，包含 `preset_name`、`category`（匯出的預設模組為 `Custom`）、`description`、`tags`、`nodes`、`edges`、`exposed_inputs`、`exposed_outputs` 與 `exposed_params`。匯出與內建的預設模組都儲存在 `backend/app/presets/`。匯出的預設模組使用 `<name>.json`；其檔名為小寫，空格與斜線會換成 `_`。系統沒有重新命名或刪除預設模組的 route 或按鈕。若要移除預設模組，請刪除其檔案並重新載入節點。[外掛包](./plugins)也能從自己的 `presets/` 目錄提供預設模組。

## REST API

| 端點 | 方法 | 說明 |
|----------|--------|-------------|
| `/api/presets` | GET | 列出預設模組定義。 |
| `/api/presets/{name}` | GET | 取得單一預設模組定義（未知時回傳 `404`）。 |
| `/api/presets/create` | POST | 從圖建立預設模組。body 為 `{name, nodes, edges, description?, category?, tags?}`，且 request 需要 session token。圖為空、含有收合區塊，或沒有未連接的連接埠時回傳 `400`。名稱已被使用時回傳 `409`。 |

請參閱完整的 **[API 參考](./api-reference)**。

:::tip 預設模組 vs 自訂節點
當你想封裝*一張由既有節點組成的圖*時，使用**預設模組**。當你需要用 Python 實作*新行為*時，撰寫一個 **[自訂節點](./custom-nodes)**。
:::
