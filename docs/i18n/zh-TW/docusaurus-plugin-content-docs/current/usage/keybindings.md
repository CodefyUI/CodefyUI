# 快捷鍵

在 input、textarea 或註記中輸入文字時，系統會忽略鍵盤組合鍵。

| 操作 | 按鍵／手勢 |
|--------|---------------|
| 復原 | `Ctrl/Cmd` + `Z` |
| 重做 | `Ctrl/Cmd` + `Shift` + `Z` / `Ctrl/Cmd` + `Y` |
| 複製選取的節點 | `Ctrl/Cmd` + `C`（頁面上有選取文字時會優先複製文字） |
| 貼上節點 | `Ctrl/Cmd` + `V`（同上） |
| 刪除選取的節點／連線 | `Delete`（`Backspace` 不會有作用） |
| 多選 | `Shift` + 點擊 |
| 框選 | `Shift` + 在空白畫布上拖曳（直接拖曳會平移畫布） |
| 快速新增節點／預設組合 | 雙擊空白畫布；按 `Up` / `Down` 再按 `Enter` 選取，按 `Esc` 關閉 |
| 開啟節點詳情 | 選取一個節點後按 `Enter`；雙擊節點；右鍵 → 開啟節點詳情 |
| 雙擊的例外 | `SequentialModel` → 模型架構編輯器；子圖實例 → 進入子圖；預設組合 → 設定預設模組；註記 → 編輯 |
| 略過／取消略過選取的節點 | `Ctrl/Cmd` + `B`（選取可略過的節點時）；右鍵 → 略過這個節點 |
| 收合／展開側邊欄 | 沒有選取可略過的節點時按 `Ctrl/Cmd` + `B`；`Ctrl/Cmd` + `Shift` + `B` 永遠有效 |
| 自動排版（上次使用的模式） | `Shift` + `L` |
| 儲存圖表（僅限專案模式） | `Ctrl/Cmd` + `S` |
| 顯示快捷鍵總覽 | `?` |
| 提交（版本控制訊息框） | `Ctrl/Cmd` + `Enter` |
| 重新命名節點 | 右鍵 → 重新命名，或使用節點詳情中的名稱欄位（`Enter` 套用，`Esc` 取消） |
| 複製節點 | 右鍵 → 複製 |
| 節點詳情導覽 | `Left` / `Right` 移到上一個／下一個節點；`Esc` 關閉 |
| 確認／提示對話框 | `Enter` 確認，`Esc` 取消 |
| 重新命名分頁 | 雙擊分頁；`Enter` 套用，`Esc` 取消 |
| 側邊欄圖示列 | `Up` / `Down` / `Home` / `End` 在分頁間移動；點擊已開啟分頁的圖示可收合 |
| 拆下／重新接線 | 以滑鼠左鍵拖曳已連接的輸入連接埠（放到空白處會刪除連線；按住 `Shift` / `Ctrl` / `Alt` 再拖曳則會改為建立新連線） |
| 連線摘要 | 執行後點擊連線；**查看統計**會開啟節點詳情 → 統計 |
| 新增註記 | 在空白畫布上按右鍵 → 新增文字註記／新增圖片註記 |

:::tip
隨時按 `?` 即可開啟應用程式內的總覽，其中列出最常用的快捷鍵。
:::
