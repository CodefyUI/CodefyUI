# 畫布基礎

CodefyUI 是單頁應用程式，中央是**畫布**，左側是**側邊欄**，選取節點時右側會顯示**設定面板**，底部則是**結果面板**。本頁說明這些區域及其主要控制項。

## 側邊欄 {/* #the-sidebar */}

左側邊欄是一列以圖示切換的分頁；本頁說明**節點**、**預設組合**、**範例**與**自訂與外掛**。點擊目前分頁的圖示或按 `Ctrl/Cmd`+`Shift`+`B`，可將面板收合成圖示列。拖曳面板邊緣可將寬度設為 180 至 520 px，瀏覽器會在重新載入後保留此寬度。

- **節點**會依顏色標示的類別列出所有節點，並提供搜尋、**全部展開**、**全部收合**與類別捷徑。**節點分類模式**設定可切換為**入門**或**全部**；前者顯示基本類別，後者顯示 16 個類別中的全部 152 個內建節點。請參閱[節點參考](./node-reference)。需要[選用套件包](./optional-packs)的節點會顯示**需要套件**標籤。你可以先放置這些節點，但套件尚未安裝時，執行會失敗並指出所需套件。
- **預設組合**會列出可搜尋並拖曳到畫布的可重用節點群組。
- **範例**會列出範例圖。點擊範例可將它插入目前畫布，或拖曳範例以選擇放置位置。請參閱[範例集](./examples-gallery)。
- **自訂與外掛**提供**自訂節點 → 管理...**、**選用套件 → 套件中心...**與**外掛 → 外掛中心...**。請參閱[外掛中心](/advanced/plugins#plugin-center)。已安裝的[外掛包](/advanced/plugins)會將 `foundations:Edu-KNN` 等使用命名空間的節點加入**節點**分頁。

## 畫布

- **新增節點。** 從側邊欄拖曳節點，或**在畫布上雙擊**以開啟快速搜尋，再輸入節點或預設組合名稱。
- **選取節點。** 點擊節點，或使用 `Shift`+點擊選取多個節點。按住 `Shift` 並在空白畫布拖曳可框選；不按 `Shift` 拖曳則會平移畫布。
- **開啟節點詳情。** 雙擊節點，或選取節點後按 `Enter`。**節點詳情**會顯示參數、連接埠與說明。執行後還會顯示錄製的輸出與統計。
- **套用自動排版。** 按 `Shift`+`L` 將圖由左至右排列，並讓檢視範圍符合排版結果。排版會將 skip connection 繞過的管線區段放在該連線下方。這會讓 U-Net 呈 U 形、將 residual block 的節點放在 bypass 連線下方，並讓簡單鏈維持單一直線。預設的**排版實驗**只排列含有 `Start` 節點的連通節點群組。工具列的**自動排版**選單也提供**排版全部**與**排版選取**。`Shift`+`L` 會重複上次選擇的模式。未綁定的註記會留在原位。

所有快捷鍵請見 **[快捷鍵](./keybindings)**。

## 連線 {/* #edges */}

- **建立連線。** 從輸出連接埠拖曳到輸入連接埠。每個連接埠都有明確的資料型別，例如 Tensor、Model、Dataset、DataLoader、Optimizer、Loss、Scalar、String、Image、List、Transform 或 Trigger。不相容的放置會被拒絕。
- **拆下或重新連接連線。** 以滑鼠左鍵拖曳已連接的輸入連接埠。將連線放到另一個連接埠可重新連接，放到空白處則會刪除。刪除前會顯示紅色圓環。拖曳時按住 `Shift`、`Ctrl` 或 `Alt`，則會建立另一條連線。
- **檢視連線值。** 執行後點擊連線，可查看該連線所傳值的型別、shape、dtype、min、max 與 mean。**查看統計**會開啟該節點的**統計**分頁。
- **變更連線樣式。** 在**設定 → 編輯器**中，選擇預設的電路板走線或平滑曲線來顯示資料連線。

## 註記 {/* #notes */}

在空白畫布上按右鍵，並選擇**新增文字註記**或**新增圖片註記**。雙擊文字註記可編輯內容。點擊圖片註記可上傳圖片；CodefyUI 會將圖片縮小至最多 800 px，並儲存在圖中。註記的右鍵選單提供**綁定到最近的節點**、**解除綁定**、**更改顏色**（Yellow、Blue、Green、Red、Purple 或 Gray）與**刪除**。已綁定的註記會以一條線連至節點，並在自動排版時跟著節點移動。未綁定的註記會留在原位，通知會指出它未被重新定位。

## 工具列 {/* #toolbar */}

工具列由左至右包含以下控制項：**執行**或**停止**；**檔案**（**儲存**、**另存新檔...**與**清除畫布**）；**載入**（可搜尋的已儲存圖與**匯入 JSON...**）；**匯出**（**匯出為 JSON**、**匯出架構圖 (SVG)**、**匯出架構圖 (PNG)**、**匯出為子圖**與**匯出為 Python**）；**範例圖庫**；**重新載入節點**；**自訂節點**；**自動排版**及其模式選單；狀態指示點；已安裝外掛新增的控制項；**設定**；顯示快捷鍵清單的 **?**；UI 字級控制項；以及語言控制項。在專案模式下，徽章會顯示目前開啟的專案名稱。儲存、載入與匯出方式請參閱 **[分頁與持久化](./tabs-persistence)**。

## 設定面板

選取節點後，右側面板會顯示其參數。後端定義會決定參數元件，包括整數、浮點數、文字、布林值、下拉選單（`select`）、模型與圖片檔案選擇器，以及內嵌的張量格狀編輯器。具有 `visible_when` 規則的參數，只有在相關選項符合其中一個指定值時才會顯示。

基本參數會直接顯示。其他參數位於預設收合的**進階**區段，其標題會顯示隱藏的參數數量。進階參數會儲存在圖中、包含在 Python 匯出結果內，且處理方式與基本參數相同。

系統會先套用條件顯示規則，再計算進階參數數量。例如，`Optimizer` 使用 `SGD` 時，數量不會包含 Adam 的 `betas`，因為該參數不適用。規則可以列出多個接受值，因此九種優化器中有四種共用的參數，會在這四種優化器下顯示。

設定面板與**節點詳情**使用相同的表單元件，因此會顯示相同的參數控制項。

## 結果面板

底部面板有多個分頁，並可調整大小或收合：

- **執行紀錄**會顯示執行期間各節點的狀態，以及 `Print` 節點的輸出。
- **訓練**會顯示 `TrainingLoop` 提供的即時 loss 曲線與 epoch 表格，包括 loss、delta 與 time。`TrainingLoop` 開始並回報設定前，此分頁會停用；回報後會自動選取（**執行任務**分頁開啟時除外），epoch 列則在每個 epoch 完成時加入。
- **執行任務**會列出伺服器擁有的執行，包括排隊中、執行中與已完成的狀態。請參閱[執行佇列](./run-queue)。

已安裝的外掛可以新增其他分頁。

## Start 節點驅動執行

每個可執行的圖都需要至少一個 **`Start`** 節點。將其 Trigger 輸出（以菱形連接點顯示）連至第一個要執行的節點。可執行集合包含每個由 Trigger 連線直接指定的節點、其下游資料流、向該集合供應資料的所有上游節點，以及每個已到達的預設組合或子圖容器內部的根節點。圖中沒有 `Start` 連線時，**執行**會拒絕該圖，並顯示要求新增及連接 `Start` 節點的錯誤。詳情請參閱 **[你的第一個圖](./first-graph)**。

## 設定 popover

工具列的**設定** popover 將控制項分成以下區段：**執行**、**LLM 提供者**、**選用套件**（[**套件中心**](./optional-packs)）、**外掛**（[**外掛中心**](/advanced/plugins#plugin-center)）、**錄製與檢視**、**訓練行為**、**編輯器**，以及**這台伺服器**。各區段的設定列見[設定 popover 的開關](./teaching-inspector#設定-popover-的開關)；其中的錄製與梯度控制項會決定 **[教學檢視器](./teaching-inspector)**可以顯示的資料。
